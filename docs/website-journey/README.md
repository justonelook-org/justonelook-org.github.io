# Just One Look website journey

This directory preserves the evolving account of how the Just One Look website has developed and how its structure fits together.

## Files

- `just-one-look-website-journey.pdf` is the August 2026 reader-facing edition.
- `updates.md` records later changes that should be incorporated into the next PDF revision.

## When to update it

Update the journey after a meaningful change to the site's public structure, Zero's architecture, measurement model, ownership, or publishing workflow. Routine copy edits and small visual adjustments do not need to be recorded.

When the PDF is revised:

1. Check the description against the production repository.
2. Replace the PDF using the same stable filename.
3. Keep displayed URLs as plain, non-clickable text.
4. Check internal routes, terminology, page order, and representative rendered pages.
5. Record the revision in `updates.md`.

Temporary source files, page renders, and review images should remain outside this directory.
